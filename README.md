# ⚡ پروژه‌های من | My Apps

یک ویترین تعاملی، مدرن و مینیمال بر پایه **پالت رنگی نوردیک (Nordic Palette)** به همراه **پنل مدیریت امن و تفکیک‌شده (Admin Portal)** جهت دسترسی سریع، پیش‌نمایش زنده، دریافت اسکرین‌شات خودکار و مدیریت کلیه وب‌اپلیکیشن‌ها و ابزارها.

---

## ✨ ویژگی‌های برجسته (Key Features)

1. **طراحی مینیمال نوردیک (Nordic Color Harmony)**:
   - پیاده‌سازی بر اساس ۵ رنگ اصلی نوردیک: Nordic Charcoal (`#1F2933`)، Fjord Gray (`#6B7280`)، Cloud Gray (`#D1D5DB`)، Snow Cream (`#F7F7F2`) و Warm Wood (`#A68A64`).
   - پشتیبانی یکپارچه از دو حالت تاریک (Dark Mode) و روشن (Light Mode) بدون پرش تصویر هنگام بارگذاری (Zero FOUC).
   - پس‌زمینه تعاملی با ذرات متحرک نوردیک متناسب با حالت تم.

2. **هیرو فشرده و رابط کاربری خلوت (Decluttered & Compact Hero)**:
   - حذف بخش‌های شلوغ و اضافه و شروع سریع با عنوان «پروژه‌های من»، زیرعنوان تک‌خطی، باکس جستجوی آنی با کلید میانبر `Ctrl+K` و فیلترهای دسته‌بندی.

3. **دریافت خودکار اسکرین‌شات از وب‌سایت‌ها (Auto-Screenshot Covers)**:
   - در صورت وارد کردن آدرس اینترنتی (Live URL) یک برنامه، تصویر پیش‌نمایش به صورت خودکار با API میکرولینک (و فال‌بک Thum.io / گرادیان نوردیک) ساخته می‌شود.

4. **دو زبانه و پشتیبانی کامل از RTL/LTR**:
   - سوییچ در لحظه بین زبان **فارسی (RTL)** و **انگلیسی (LTR)** با متون کوتاه، شیک و به‌روز.

5. **کنترل‌پنل مدیریت تفکیک‌شده و امن (Standalone Admin Portal)**:
   - تفکیک کامل از لندینگ‌پیج در مسیر اختصاصی `/admin` با احراز هویت امن JWT و کوکی‌های HttpOnly.
   - نام کاربری پیش‌فرض: `admin` | رمز عبور پیش‌فرض: `1234`
   - ثبت، ویرایش، تکثیر سریع (Duplicate) و حذف با تأییدیه.
   - کلید اختصاصی اسکرین‌شات خودکار از آدرس برنامه.
   - خروجی و بازیابی با فایل JSON.

6. **پشتیبانی دوگانه از ذخیره‌سازی (Dual-Mode Persistence)**:
   - سرور Node.js محلی با ذخیره مستقیم در فایل دیسک `data/apps.json` و اتصال ابری به دیتابیس **Turso (libSQL)** در ورسل.

## 🚀 نحوه اجرا (How to Run)

### روش اول: اجرای با سرور Node.js
```bash
npm start
```
یا
```bash
node server.js
```
سپس در مرورگر به آدرس زیر بروید:
👉 **[http://localhost:3000](http://localhost:3000)**

---

### روش دوم: ورود به پنل مدیریت
1. در مرورگر به آدرس `/admin` (یا `http://localhost:3000/admin`) بروید.
2. نام کاربری: `admin` | رمز عبور: `1234`
